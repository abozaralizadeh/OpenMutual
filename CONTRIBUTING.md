# Contributing

Thanks for wanting to help.

- For anything big, open an issue first so we can talk it through.
- Run `npm test` before you send a pull request, and make sure it passes.
- Keep everything local: no real keys, no public networks and no paid services. If something needs an outside service, put it behind an interface with a local fake, like the ones in `shared/src/`.
- The product never calls itself insurance. It's a simulation with test money.
