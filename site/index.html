A risk pool run by its members, not by a company.

OpenMutual is an open experiment. People buy small covers with clear rules, like 100 if a flight is 3 hours late. Other people back the pool that pays them and earn what's left. Smart contracts hold the money and the rules, so anyone can check them.

It runs on your own machine with worthless test dollars, so you can try every part of it without risking anything.

How it works

1

Backers fill the pool

They get pool shares. Their earnings show up as a higher share price, and they can withdraw after a 7 day wait.

2

Members buy cover

Late flight, rainy day or lost bag. Every cover locks its full payout, so the pool never owes more than it holds.

3

Data decides

Three sources report what happened and two must agree. Nobody files a claim for a late flight. Lost bags go to a member vote.

4

The contract pays

If the rule is met, the payout goes out by itself. If not, the price stays in the pool and backers earn it.

Quick install

You need Node.js 24 or newer. The local chain and the contract tools come from npm, so there's nothing else to install.

git clone https://github.com/abozaralizadeh/OpenMutual.git openmutual
cd openmutual
npm install
npm run dev

Then open http://localhost:3417. Sign in with any email, the code shows on screen, and you start with 10,000 test dollars.

Run every test with npm test. The browser tests need Google Chrome.

Why there's no live demo here. The app needs a chain, a background worker and a server, so it can't run as a static page. Installing it takes a couple of minutes.

What's faked

  • A local test chain in place of a public one
  • Test dollars worth nothing
  • Made up flight and weather data from three fake sources
  • Email codes shown on screen, a stand-in identity check, and five pretend members who vote

Each fake sits behind an interface, so a real one could replace it later.

The contracts haven't been audited. Please don't use any of this with real money. The code refuses any chain that isn't local.
