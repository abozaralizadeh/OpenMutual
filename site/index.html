HOW

Three steps. Then the data takes over.

No claim forms and nobody judging a claim. The rules live in the contracts, and the result comes from the data.

01

Back the pool

Put in test dollars and get pool shares. Backers earn what's left of the prices after payouts, and they can lose some too.

02

Buy a cover

Pick a flight and see the price before you pay. Buying locks the whole payout in the pool, so it's there if the flight is late.

03

Let the data decide

Three sources report the flight. When two agree and a 1 hour check passes, the payout goes out on its own.

WHY

Built so the pool can always pay.

A few hard rules do most of the work. They're in the contracts, and the tests try to break them on every run.

Every number in the open

Pool totals, a balance check and the share price come straight from the chain, so anyone can check them.

One member, one vote

Members vote on lost bag claims and on three pool settings. Putting in more money doesn't buy more votes.

The full payout is locked at sale

Every cover holds back its whole payout until it ends, so the pool never promises more than it has.

Two of three sources must agree

One bad data feed can't decide alone. After that there's a 1 hour window to reject a wrong result.

A 7 day wait to leave

Backers can't pull out right before a storm. The wait has no cancel, and losses during it are shared.

Nothing leaves your laptop

It runs on a local test chain with test dollars. The code refuses any other network, so nothing real is at risk.

RUN

Running on your laptop in a few minutes.

1 · Get the code 
$ git clone https://github.com/abozaralizadeh/OpenMutual.git
$ cd OpenMutual
$ npm install
2 · Start everything 
$ npm run dev
3 · Run every test 
$ npm test
1

Node.js 24 or newer. The local chain and the contract tools come from npm, so there's nothing else to install.

2

Open localhost:3417. Sign in with any email. The code shows on screen, and your test wallet starts with 10,000 test dollars.

3

Skip the clock. Buy a cover, set a flight late from the admin page (the token prints in your terminal), skip a few days and watch it pay out.

4

Tests: contracts, unit, full flows on a real local chain, and browser tests. The browser tests need Google Chrome.

FAQ

The honest bits.

Is this insurance?

No. It's a simulation with test dollars that are worth nothing. Nothing is for sale, and it isn't insurance or an investment.

Can I put real money in?

No. The code refuses any chain that isn't local, the contracts haven't been audited, and the server holds everyone's test keys. Please don't use any of it with real money.

What's faked?

The chain, the money, the flight and weather data, email, the identity check and the five pretend members who vote. Each fake sits behind an interface, so a real one could replace it later.

Why a video and not a live demo?

The app needs a chain, a background worker and a server, so it can't run as a static page. The video is the real app. Installing it yourself takes a few minutes.

Can I use the code?

Yes, for anything non-commercial. It's source available under PolyForm Noncommercial 1.0.0. For commercial use, ask for written permission through a GitHub issue.

Can I help?

Yes. Issues and pull requests are welcome. Read CONTRIBUTING.md first, because contributions are accepted only if they can be relicensed.
